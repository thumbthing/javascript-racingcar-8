# 기능 목록

---

## 입력

### 사용자 입력

1. 지정된 문구를 사용자에게 출력한다
2. 사용자에게 입력을 받는다
3. 입력된 값을 반환한다

### 자동차 이름 입력

1. 안내 문구를 지정한다 
    - 안내 문구 : `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)`
2. `getInput(안내문구)`로 안내-입력을 받는다
3. 입력 받은 값을 반환한다

### 시도 횟수 입력

1. 안내 문구를 지정한다
    - 안내 문구 : `시도할 횟수는 몇 회인가요?`
2. `getInput(안내문구)`로 안내-입력을 받는다
3. 입력 받은 값을 반환한다

---

## 변환

### 문자열 -> 배열 변환

1. 입력 받은 문자열을 배열로 변환
    - `split()` 메서드로 `,` 를 기준으로 분리
2. 생성된 배열을 반환

### 문자열 -> 숫자 변환

1. 입력 받은 문자열을 숫자로 변환
    - `Number()`로 변환
2. 생성된 숫자를 반환

---

## 검증

### 자동차 입력값 검증

1. 배열로 변환된 배열을 순회한다
    - `every()`로 순회한다
      - 자동차 이름이 5글자 이하일 경우 다음 요소를 확인한다
        - 마지막 요소까지 유효하면 `true`를 반환한다
      - 자동차 이름이 5글자를 초과할 경우 `false`를 반환하고 순회는 중지된다
      - 자동차 이름이 빈 문자열일 경우 `false`를 반환하고 순회는 중지된다
2. 순회하여 반환된 결과를 확인한다
    - 결과가 `false`일 경우 `Error`를 생성하고 `throw`한다
