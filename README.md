## 기능

### 기능 흐름

#### 초안

1. 화면에 안내 문구가 출력된다
    - 경주할 자동차 이름 입력 방법에 대한 안내 문구를 출력
2. 사용자가 경주할 자동차를 입력한다
3. 입력 값을 변환한다
    - `,`를 기준으로 입력값을 분리한다
4. 변환된 입력값의 유효성을 검사한다
    - 분리된 입력값이 빈값인지
    - 분리된 입력값이 5자를 초과하는지
    - 둘중에 하나라도 해당할 경우 `[ERROR]`를 포함한 에러를 발생 시킨다
5. 화면에 안내 문구가 출력된다
    - 이동 횟수에 대한 문구를 출력
6. 사용자가 이동 횟수를 입력한다.
7. 입력된 값을 변환한다
    - `String` -> `Number`로 변환한다
8. 변환된 입력 값의 유효성을 검사한다
    - 변환된 입력값이 양의 정수인지 확인한다
    - 유효하지 않은 경우
      - 음수
      - 소수
      - NaN
9. 이동 횟수 만큼 레이스를 진행한다
    1. 자동차 이름 목록에서 하나의 자동차 이름을 선정한다
    2. 지정한 범위내의 무작위 숫자를 생성한다
    3. 진행 여부의 범위를 지정한다
    4. 생성된 무작위 숫자가 진행 여부의 범위 내의 숫자인지 판단한다
        - 범위 내의 숫자일 경우 : 진행한다
        - 범위 내의 숫자가 아닐 경우 : 진행하지 않는다
    5. 선정된 자동차에 진행 현황을 최신화한다
    6. 모든 자동차의 진행 현황이 최신화 되었으면 현재 결과를 출력한다
    7. 이동 횟수 만큼 레이스를 반복한다
10. 자동차 이름 목록에서 진행 현황을 확인한다
11. 가장 많이 이동한 자동차 이름을 판별한다
    - 가장 많이 이동한 자동차를 우승자 목록에 추가한다
    - 가장 많이 이동한 자동차가 여러대 일 경우 해당하는 모든 자동차 이름을 우승자 목록에 추가한다
12. 우승자 목록을 화면에 출력한다
